Portail Active Directory — AtlasGroup / AtlasTech

Déploiement local :
1. Extraire le contenu complet de cette archive dans un même dossier.
2. Ouvrir index.html dans un navigateur moderne.
3. Conserver le dossier media/ à côté de index.html pour afficher les captures.

Le portail est une page HTML interactive. La mise en forme principale est intégrée au fichier ; le chargement optionnel de Tailwind utilise le CDN officiel. Les images de la source DOCX sont copiées sous media/.
